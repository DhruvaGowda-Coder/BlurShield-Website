## Privacy summary

BlurShield detects and visually protects sensitive page content locally in the browser. Detected secrets and webpage content are not uploaded. Optional Google Sign-In and free-trial records use Google/Firebase services, while license validation uses Lemon Squeezy. See the published Privacy Policy for the complete disclosure.
